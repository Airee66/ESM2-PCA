App

The actual interactive app is a Python/Streamlit application and cannot run directly on GitHub Pages. The GitHub Pages site is the landing page, while the app itself should be deployed with Streamlit Cloud, Hugging Face Spaces, or another Python host.

Deploy Streamlit App

Local run

  • conda activate esm2-env
  • streamlit run app.py
  • Open http://localhost:8501
